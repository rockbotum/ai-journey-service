# ADR 0002: Идемпотентность и конкурентное изменение

Статус: принято
Дата: 2026-09-30

## Контекст

Подтверждение бронирования и отмена — финансовые операции. Повтор запроса из-за
сети, таймаута или нажатия кнопки дважды не должен приводить к двум
подтверждениям или двойному списанию. При этом две параллельные операции над
одним бронированием не должны обе завершиться успешно.

## Решение

1. **Ключ идемпотентности обязателен** для любого изменяющего состояние запроса.
   Без заголовка `Idempotency-Key` запрос отклоняется с кодом 400.

2. **Ключ связан с отпечатком запроса.** При повторе ключа с тем же запросом
   возвращается результат первого выполнения. При повторе ключа с *другим*
   запросом возвращается 409. Отпечаток строится по содержанию запроса и
   намеренно не включает идентификатор брони и время: иначе настоящий повтор
   выглядел бы как другой запрос.

3. **Идемпотентность обеспечивается хранилищем, а не памятью процесса.**
   Таблица `idempotency_keys` с первичным ключом по ключу. Иначе повтор,
   попавший на другой инстанс, вёл бы себя иначе.

4. **Оптимистическая блокировка.** У каждой строки есть `version`. Переход
   состояния возможен только при совпадении прочитанной версии; в БД это
   реализовано одной функцией `apply_booking_transition`, которая в одной
   транзакции проверяет версию, обновляет состояние и пишет запись аудита.
   Обойти её обычным `UPDATE` нельзя: триггер запрещает изменение терминальных
   состояний.

5. **Финансовый вызов не повторяется автоматически.** `provider.HTTPClient`
   никогда не переигрывает подтверждение сам: слепой повтор — это риск второго
   списания. Идемпотентность на стороне поставщика обеспечивается передачей
   того же ключа.

## Последствия

- Повтор запроса дешевле, чем новая операция, но требует от клиента сохранять
  ключ при ретраях.
- Возможен конфликт версий (409) при гонке; клиент должен повторить чтение
  состояния, а не blindly повторять операцию.
- Ключи идемпотентности хранятся вместе с бронированием и удаляются каскадно,
  то есть защита действует в течение жизни брони.
